# Stage 05 — Local LLM (The Higher Brain)

Routes conversational / open-ended queries to a local LLM (Ollama running Llama 3 or similar).

## Status: 🔲 Not yet implemented

## Requirements

- Ollama installed locally (`brew install ollama`)
- A model pulled (`ollama pull llama3`)

## Test standalone

```bash
cd stages/05-llm
npm install
node index.js
```
